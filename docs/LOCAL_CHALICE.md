# Offline Chalice Glyphs (LocalChalice)

Chalice Dungeons by glyph without a server. When the game is **offline**, the Ritual Altar's
network items work again, from a local catalog of **2351** community glyph dungeons:

- **Search by Chalice Glyph**: type a glyph in the game's own glyph box; after the game's own
  confirmation the dungeon is placed on the current altar at once (no reload), and the game's own
  message box says so. The altar menu then closes; the next visit enters the dungeon.
- **Chalice Dungeon Search** becomes a glyph list built with the game's own menu pages: the
  glyphs' first characters (with counts), then the glyphs in alphabetical order. The help line
  under a glyph is a short description in the game's language (below).
- The same glyph may be placed on several altars, as in the original.
- **Online play is untouched.** Every change applies only while the FROM client has no session;
  with `BB_ONLINE=1` (an online launch) or under BBSC nothing is installed.

Switch it off with `BB_LOCAL_CHALICE_NATIVE=0` (the launcher's extra variables).

## Descriptions in 21 languages

Each glyph's help line is composed at run time from the game's **own text** in the language the
game runs in (the catalog stores text ids, never game text):

`L1 Bath Messenger, Rare layout · L2 Hidden path · Lower Loran Chalice · Keeper of the Old Lords / …`
`L1 浴缸信使、稀有布局 · L2 隐藏通路 · 下层洛然圣杯 · 旧领主的守卫者 / …`

Farm / false depth first, then what each layer has (Caryll Runes, Blood Gems with their shape and
effect exactly as the gem screen writes them, chalice weapons, tags, that layer's boss), then the
chalice and the other bosses; at most 150 columns (CJK counts 2), bosses dropped first when longer.
Only four words are the mod's own (Farm, Rare layout, Glitch, False depth) and its ten message
sentences (`tools/local_chalice/messages.json`, translated for all 21 languages with the game's
official terms for Chalice Glyph, Ritual Altar and Chalice Dungeon). The language is recognised
from a hash of a few game texts; an unknown one falls back to English words.

## How it works (1.09 eboot)

`src/probe.c` calls `lc_prepare(image, size)` after the patches are applied, before the game runs
(Windows build). `src/local_chalice.cpp` first checks every byte it relies on and installs
nothing if any differs (another patch or mod changed it, or not 1.09):

| Address | Game function | Change |
|---|---|---|
| 0x1aa64c0 | CSDungeonRitualHelper::STEP_Wait_forRequest | hook: observes the altar reload finishing |
| 0x1b70da0 | glyph search continuation (would start the network search) | hook: offline, places the dungeon |
| 0x1c1d420 | menu page step update | hook: closes the altar pages after a placement |
| 0x1b76150 | menu add-item | hook: our pages' items, only while building them |
| 0x1b68200 | "Chalice Dungeon Search" handler | hook: offline, opens the glyph list |
| 0x1b66792, 0x1b66655 | altar page builder | 1 byte each: the two items not greyed offline |
| 0x1b6884f | glyph handler | 2 NOPs: skips the "offline" notice |

Functions it only calls (event flags 0x13cfd80 / 0x13d0060, the altar's resume request 0x1aa40e0,
text 0x1ae8cc0 and the message lookup 0xf6f340, the OK box 0x1c1f500, the altar page builder
0x1b66470) are recognised by 16 bytes of their bodies, so a hook on their entry by something else
does not matter.

A placement writes the dungeon record into the current altar slot's event flags (94000000 +
slot·100000, 43 words) through the game's own SetEventFlagValue, exactly as the game does when it
joins a glyph dungeon online; only an empty slot is written, every word is read back, and a failed
write is undone. The dungeon is generated by the game from that record as always. The altar's
helper then reloads it with the game's own Resume request.

## Data and credits

- `data/local_chalice/catalog.bin`: glyph, dungeon parameters (FormData), creator names and the
  description recipes; built by `tools/local_chalice/` (`make_catalog.py`, then
  `make_catalog_v4.py` with a game dump's `msg` folder).
- Glyph list and notes: **[BB.Chalices.Reborn](https://github.com/LL4nc33/BB.Chalices.Reborn)**
  by LL4nc33, MIT license (`data/local_chalice/LICENSE-BB.Chalices.Reborn.txt`).
- Dungeon records and creator names of 187 glyphs: **[Noxde's dungeon list](https://gist.github.com/Noxde/a29f699f4175bf315d9bd4baeebefb66)**
  by Noxde. Every creator name the mod shows comes from here, so the "by …" part of each help line
  is Noxde's work.
- No game files: descriptions are game text ids composed at run time.

Written with AI assistance (Anthropic's Claude), reviewed and tested by the author: in game on
Windows (Supermedo 1.9.7), and offline against the 1.09 code (all checks, all hooks), and the
description composer against a Python reference for every glyph in all 21 languages.
`tests/test_local_chalice.py` checks the shipped catalog.
