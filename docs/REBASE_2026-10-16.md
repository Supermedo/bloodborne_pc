# Windows development rebase — 2026-10-16

Base: upstream `windows` at `fce08780508a72f50d34a3d3a2926e746d12284c`
(version 1.8.2). This repository has no separate `dev` branch. The previous
integration is preserved at `b2b3d4b0cd5b391105372cc27fa7306902ef99b4`.

The rebase keeps upstream's native The Hunter's Dream backend and removal of
the external online bridge, filesystem compatibility changes, guest-memory
fallback, sprint handling, flip-IRQ recovery, title-menu classification,
loading-screen stencil handling, and optional-DLSS device-creation fallback.
Those implementations come from upstream rather than competing local copies.

Remaining local changes include DLSS/FSR frame generation and its completion,
pacing and resource-lifetime fixes; Reflex frame ownership and source-queue
policy; reconstruction sharpening, mip bias and linear-input handling; guarded
bridge rejection; custom outputs and arbitrary-aspect camera support; and
output-space UI/mouse mapping. Upstream's HUD-position control remains usable,
with the existing integration's centered default. The physical UI viewport
stays separate from the logical canvas used to position the HUD layer.

The FG scheduler, presenter, Reflex implementation, capped/uncapped delivery
code, NVIDIA adapter, and all five FSR vendor patches are unchanged from the
previous integration. The renderer incorporates upstream's additional menu
shader hashes and loading-screen mask handling.

Validation on Windows:

- CLANG64 RelWithDebInfo runtime, capability tool and play helper compile.
- The launcher is frozen again from the updated version 1.8.2 source.
- Focused Python checks: 69 tests, one optional dump-dependent skip.
- Ten native CPU suites pass, including the protected-page bridge test.
- Both FG shaders compile and pass SPIR-V validation; the paired NVIDIA
  adapter's ABI-2 table passes its CPU-only check.
- Broad Python discovery was attempted, but is not a passing cross-platform
  result: nine checks encountered Linux shell/filesystem assumptions or
  unavailable Windows symlink privileges. The additional Linux-oriented pad
  test also requires POSIX environment functions absent from the native Windows
  toolchain. These are recorded separately from the passing focused checks.

No gameplay, frame-pacing or online-session validation was run for this rebase.
The measurements in `GPU_VALIDATION.md` refer to the older executable identities
listed there; they are not measurements of this rebuilt version. The previous
validated package remains available separately.
