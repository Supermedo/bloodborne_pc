## 1. Маска реактивности не сохраняется ✅ ИСПРАВЛЕНО

### Проблема
Чекбокс "Показать маску (отладка)" в меню работал, но настройка `debug_view` не сохранялась в `bbport.ini`, поэтому после перезапуска маска не отображалась.

### Причина
В `bbport_settings.cpp`:
- Функция `Set()` не обрабатывала ключ `debug_view`
- Функция `Save()` не записывала значение `debug_view` в файл

### Исправление
**Файл:** `native_probe/gpu/shim/bbport_settings.cpp`

1. Добавлена обработка в `Set()`:
```cpp
} else if (key == "debug_view") {
    v.debug_view = std::clamp(i, 0, DebugViewCount - 1);
}
```

2. Добавлена запись в `Save()`:
```cpp
"debug_view=%d\nshow_fps=%d\n",
// ...
v.debug_view.load(), int(v.show_fps.load())
```

### Как проверить
1. Запустить игру
2. Открыть меню (Insert или L3+R3)
3. Включить "Маска реактивности" → "Показать маску (отладка)"
4. Закрыть меню
5. Маска должна отображаться красным цветом поверх затемнённого кадра

## 2. Шлейфы на оружии

### Анализ
Из логов видно:
```
Object motion: on (4194304 vertices per frame)
```

Векторы движения объектов включены и работают. Шлейфы могут быть из-за:

#### Возможные причины:

**A. Проблема FSR 3.1**
- FSR 3.1 может неправильно обрабатывать быстро движущиеся объекты
- Нужно сравнить с FSR 4 (когда будет реализован)

**B. Векторы движения объектов неточные**
- Выборочный путь включает векторы только для отрисовок с буферами поз/костей
- Возможно, оружие на спине использует другой тип анимации

**C. Маска реактивности не работает для оружия**
- Маска помечает только прозрачные эффекты (частицы, дымка)
- Оружие — непрозрачный объект, поэтому маска на него не влияет

**D. Jitter выключен**
Из `bbport.ini`:
```
jitter=0
```
Субпиксельный сдвиг **выключен**, что ухудшает качество темпорального апскейлера!

### Рекомендации для тестирования

1. **Включить jitter:**
   ```ini
   jitter=1
   ```
   Jitter критически важен для FSR 3.1!

2. **Проверить маску реактивности:**
   - Включить `debug_view=1` и `reactive=1`
   - Посмотреть, какие области помечены как реактивные
   - Оружие НЕ должно быть в маске (оно непрозрачное)

3. **Попробовать увеличить reactive_scale:**
   ```ini
   reactive_scale=2.00
   ```
   (хотя это для прозрачности, не для оружия)

4. **Отключить векторы объектов для сравнения:**
   ```ini
   object_motion=0
   ```
   Перезапустить и сравнить — станет хуже или лучше?

5. **Проверить разные пресеты:**
   - Native AA (preset=0) — без масштабирования
   - Quality (preset=1) — x1.5
   - Performance (preset=3) — x2.0
   
   Шлейфы должны быть меньше на более высоких разрешениях рендера.

### Логи для отладки

Включить отладку векторов движения:
```bash
BB_DEBUG_MOTION=1 ./run.sh
```

Должны появиться опции:
- Toggle 1<<22: перепроецирование прошлого кадра
- Toggle 1<<23: карта ошибок

## 3. Перезапуск для применения настроек

### Текущая ситуация

Из логов:
```
GPU scene scaling: test adapter lacks blit support for D32S8
GPU scene scaling: using startup resolution 960x540 for this driver
```

Тестовый адаптер **не поддерживает blit D32S8** (копирование depth+stencil буфера), поэтому используется старый путь:
- Разрешение задаётся патчем при запуске
- Смена пресета требует перезапуска

### Новый путь (в рабочем дереве, не закоммичен)

Согласно ROADMAP.md, в рабочем дереве есть код для:
- Динамического масштабирования на уровне рендерера
- Переключения пресетов без перезапуска
- Автоматического fallback для GPU без blit D32S8

Но этот код **ещё не закоммичен** — автор ждёт тестирования на реальном GPU.

### Что работает без перезапуска

Эти настройки применяются **сразу**:
- ✅ Включение/выключение апскейлера
- ✅ Резкость (sharpness)
- ✅ Jitter (если не включён BB_LIVE_SCALING_UNSUPPORTED)
- ✅ Маска реактивности и её параметры
- ✅ Отладочные режимы

### Что требует перезапуск

На твоём GPU:
- ❌ Смена пресета (Native AA ↔ Quality ↔ Performance)
- ❌ Включение/выключение векторов движения объектов

### Обходной путь

Для тестирования разных пресетов без перезапуска игры:
```bash
# Редактировать bbport.ini
preset=1  # Quality
# Перезапустить только процесс (Ctrl+C, затем ./run.sh)
```
